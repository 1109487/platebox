      Sending over 4G? Three camera settings that keep it quick
      • Gateway and DNS: Setting → Network → TCP/IP. The gateway is the 4G gateway's address; set a DNS server (for example 8.8.8.8) if the Server address above is a name and not a number.
      • Smaller pictures: Setting → Camera → Snapshot. A smaller picture reaches the server sooner; the plate only has to stay readable.
      • The right time: Setting → System → General → Date & Time. Every plate shows the camera's own clock.
      {% else %}
      No internet at this site? Two more settings keep the camera from waiting

      The camera looks up a name and the time before it sends a picture, and without internet it waits a minute and gives up. PlateBox answers both itself. On the camera set both of these to this computer's address:

      • DNS server: Setting → Network → TCP/IP
      • NTP (time) server: Setting → System → General → Date & Time (turn NTP on)

      Worth doing at every site: it also gives the camera the right time, which shows on every plate.

      Using a router that changes addresses? Fix the addresses once

      If this computer's number changes later, the camera keeps sending to the old one and nothing arrives. PlateBox keeps working when it can, and warns you when it cannot. The lasting fix: give this computer and the camera fixed addresses (or ask the router's owner to reserve them). The steps are in Settings, under Addresses, once setup is done.
