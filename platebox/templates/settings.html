Addresses: keeping the camera and this computer in touch

The camera sends its pictures to a number you typed into it ({{ cam.ip_now or '…' }} now). On many networks the router hands out different numbers from time to time. If this computer's number changes, the camera keeps sending to the old one and nothing arrives, while live view still works. PlateBox watches for this and, when it can, keeps the camera's number working by itself.

The lasting fix: give the camera and this computer fixed addresses
  1. Pick two unused numbers on the same network, outside the router's automatic range, for example 192.168.1.200 for this computer and 192.168.1.201 for the camera (mask 255.255.255.0). Ask the router's owner for its range if you can.
  2. This computer: Windows Settings, Network & internet, your Wi-Fi or Ethernet, IP assignment, Manual, IPv4: the address above, mask 255.255.255.0, gateway the router's address.
  3. The camera: Setting, Network, TCP/IP, Static: its address, the same mask, the same gateway. Save.
  4. The camera, FTP page: Server Address is this computer's fixed address. Save, then test.

Better still, ask the router's owner to reserve those two addresses for this computer and the camera. Then neither needs setting by hand.

No internet at this site?

The camera pauses to look up a name and the time before it sends a picture. With no internet it waits about a minute, gives up, and nothing arrives, even though live view still works. PlateBox can answer those two lookups itself so the camera never waits.

Set these two things on the camera to this computer's address{% if offline_ip %} {{ offline_ip }}{% endif %}:

  • DNS server: camera page, Setting → Network → TCP/IP.
  • NTP (time) server: camera page, Setting → System → General → Date & Time (turn NTP on).
